# Ridwan Nur Aziz — Portfolio

Portfolio personal menggunakan React + Vite + Tailwind CSS.

## Fitur
- Responsive desktop / tablet / mobile
- Navbar dengan smooth scroll
- Hero section
- About
- Skills
- Experience
- Project showcase
- Contact section
- Animasi dan efek visual ringan
- Mudah diedit karena seluruh data utama berada di `src/main.jsx`

## Menjalankan project

Pastikan Node.js sudah terpasang.

```bash
npm install
npm run dev
```

Kemudian buka alamat yang diberikan Vite, biasanya:

```text
http://localhost:5173
```

Untuk build production:

```bash
npm run build
npm run preview
```

## Yang perlu Anda ganti

Di `src/main.jsx`, ubah:
- email pada tombol Email Saya
- URL LinkedIn
- URL Instagram
- detail pengalaman
- project dan link project
- skill
- foto profil jika ingin ditambahkan

Project menggunakan Tailwind CSS v4 dengan plugin Vite.
